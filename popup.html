Label or button text Value

Changes save automatically. For dropdowns and radio buttons, type the option's text. For several checkboxes under one question, choose "Multiple" and separate options with commas.

To press a button, add a row, type the button's text (e.g. Submit or Next) and choose "Click button". Rows run top to bottom; use the arrows to reorder.
